# Чудо Обувь - учебный проект

Учебный проект по МДК 02.01 «Технология и инструментальные средства разработки
программного обеспечения». Магазин обуви: база данных SQLite, сервер на встроенном
`http.server` и страница заказов на чистом JavaScript.
Сторонние библиотеки не нужны, только Python 3.8 или новее.

## Запуск

1. Создать базу и загрузить данные из Excel-файлов:
   - `python import_data.py `
   - (только пустые таблицы создаёт `python create_db.py`)

2. Запустить сервер:
   - `python server.py`

3. Открыть в браузере http://localhost:8000 и войти по логину,
   например `isivanov` (администратор) или `papetrov` (менеджер).

В Linux команды такие же, но вместо `python` может понадобиться `python3`.

## API

| Запрос | Что делает |
|---|---|
| `GET /api/login?login=...` | вход по логину, возвращает id, ФИО и роль |
| `GET /api/categories` | список категорий |
| `GET /api/products?category=&search=&sort=` | каталог с фильтром, поиском и сортировкой |
| `GET /api/product?id=N` | карточка товара с размерами |
| `POST /api/order/create` | оформление заказа, остатки уменьшаются |
| `GET /api/users?login=...` | список клиентов (менеджер и администратор) |
| `GET /api/orders?login=...` | список заказов (менеджер и администратор) |
| `GET /api/order?id=N&login=...` | состав заказа |
| `POST /api/order/update` | дата заказа и удаление позиций (только администратор) |
| `POST /api/echo` | возвращает присланный JSON (проверка POST) |

## Роли

- **Менеджер** видит заказы и их состав.
- **Администратор** дополнительно меняет дату заказа и удаляет позиции
  (товар при этом возвращается на склад).
- **Авторизованный пользователь** может войти, но раздел заказов ему недоступен.

## Оформление

Страница сделана по руководству по стилю КИМ: шрифт Calibri, белый фон, дополнительный фон #D2F6E7, цвет акцентов #70B2AF, логотип без изменений.

## Ограничения учебной версии

Вход только по логину, без пароля и сессий: роль проверяется на сервере по логину,
который присылает страница. Для настоящего сайта так делать нельзя.

## Проверочные скрипты

- `python check_db.py` - таблицы и число строк; `python check_db.py rules` - проверка ограничений.
- `python check_api.py <группа>` - проверка API запущенного сервера (static, echo, login, products, product, create, robust, orders, update, staff).
