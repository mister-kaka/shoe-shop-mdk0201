# Чудо Обувь - учебный проект

Учебный проект по МДК 02.01 «Технология и инструментальные средства разработки программного обеспечения».
Магазин обуви: база данных SQLite, сервер на встроенном `http.server` и страница на чистом JavaScript.
Сторонние библиотеки не нужны, только Python 3.8 или новее.

Проект делается по шагам (практическим работам), описание дополняется по мере работы.
