Работа: изучить документацию к технологиям, которые используются в проекте, и кратко записать главное.
Где применяется в проекте - указано в каждом пункте.

## 1. Python: модуль http.server

- Встроенный модуль для простых HTTP-серверов. В документации прямо сказано, что он не рассчитан на промышленное использование и не проверяет безопасность, поэтому подходит для учебных задач.
- `HTTPServer((хост, порт), Обработчик)` - сам сервер; `serve_forever()` запускает бесконечный цикл ожидания запросов, `server_close()` освобождает порт.
- `BaseHTTPRequestHandler` - базовый класс обработчика. Метод на каждый тип запроса называется `do_GET`, `do_POST` и т.д. - сервер сам вызывает нужный.
- Внутри обработчика доступны: `self.path` (адрес с параметрами), `self.headers` (заголовки), `self.rfile` (тело запроса), `self.wfile` (куда писать ответ).
- Порядок ответа: `send_response(код)`, затем `send_header(...)`, затем обязательно `end_headers()`, и только потом тело через `wfile.write(bytes)`.
- Применение: `server.py`, класс `Handler`.

## 2. Python: модуль sqlite3

- Работа с базой SQLite, которая лежит в одном файле; отдельный сервер СУБД не нужен.
- `connect(путь)` открывает базу (файл создаётся, если его нет), `cursor()` / `execute()` выполняют запросы, `commit()` фиксирует изменения, `rollback()` отменяет.
- Параметры запроса передаются через `?` и кортеж значений: так значения не склеиваются со строкой запроса, и это защищает от SQL-инъекций.
- `executescript()` выполняет сразу несколько команд из текста (так загружается `schema.sql`).
- `row_factory = sqlite3.Row` позволяет обращаться к столбцам по имени.
- Внешние ключи в SQLite по умолчанию выключены, нужно выполнить `PRAGMA foreign_keys = ON` для каждого соединения.
- Применение: `create_db.py` (executescript), `import_refs.py` и `server.py` (запросы с параметрами «?»).

## 3. Python: модуль zipfile

- Чтение и запись ZIP-архивов. Файл `.xlsx` - это ZIP с XML внутри, поэтому его можно разобрать без сторонних библиотек.
- `ZipFile(путь)` лучше открывать через `with`, чтобы архив закрылся сам.
- `namelist()` - список файлов внутри архива, `read(имя)` - содержимое файла в виде байтов.
- Применение: `read_excel.py`, функция `read_xlsx` (читает `xl/sharedStrings.xml` и `xl/worksheets/sheet1.xml`).

## 4. JavaScript: fetch

- `fetch(адрес, настройки)` отправляет HTTP-запрос из браузера и возвращает Promise с объектом `Response`.
- В настройках задаются `method`, `headers`, `body`.
- Важно: `fetch` не выбрасывает ошибку при кодах 4xx и 5xx - проверять нужно `response.ok` или `response.status`. Ошибка возникает только при проблемах с сетью.
- `response.json()` тоже возвращает Promise и разбирает тело ответа как JSON.
- Применение: `static/app.js`, функция `api()` (запросы страницы к серверу).

## 5. JavaScript: addEventListener

- `элемент.addEventListener(тип, функция)` подписывает функцию на событие (`click`, `submit`, `change` и т.д.).
- Функция получает объект события; через него можно, например, вызвать `preventDefault()` и отменить стандартное поведение формы.
- На одно событие можно повесить несколько обработчиков, они не затирают друг друга.
- Применение: `static/app.js`, раздел «подключаем обработчики» и перерисовка шапки (renderHeader).

## 6. JavaScript: JSON.stringify

- Превращает значение JavaScript в строку JSON, чтобы отправить её на сервер. Обратная операция - `JSON.parse`.
- Свойства со значением `undefined` и функции в объекте пропускаются.
- Применение: `static/app.js`, отправка тела POST-запроса в `api()`.
